# Changelog

## adxc-demo 1.0

- Renamed demo package from aDXC-GAMA release candidate naming to adxc-demo.
- Added MIQM dashboard files.
- Added MIQM Control, Troubleshooting, Checks and Maintenance dashboard renderers.
- Added profile operation configuration under profiles/<PROFILE>/operations/.
- Added operation management in adxc-admin.
- Added configurable Control operations for Start Node, Stop Node and Manual Failover.
- Added demo global scripts and demo command objects.
- Preserved hardened installer and user enablement model.
